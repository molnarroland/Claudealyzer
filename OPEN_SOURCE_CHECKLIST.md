# Open-source checklist

What is still missing before Claudealyzer can be published, most urgent first.

**Suggested order:** host-wails tag → npm publish → LICENSE + config.yml → CI/release workflows →
community files → first tagged release → enable Pages.

## 1. Blockers: a fresh clone won't build

- [ ] **Go uses a local folder for host-wails.** `go.mod` has
      `replace github.com/spartan-native/host-wails => ../host-wails`.
      Push a `v0.1.0` tag to Spartan-Native/host-wails (it has no tags yet), then delete the `replace`
      line and run `go mod tidy`.
- [ ] **The frontend uses vendored tarballs.** `frontend/package.json` points five `@spartan-native/*`
      packages at `file:libs/*.tgz`. Once they are on npm, switch to normal version numbers and delete
      the `.tgz` files. Until then, say in DEVELOPMENT.md that this is temporary.
- [ ] **The Go module has a local-only name** (`module claudealyzer`). Rename it to
      `github.com/<user>/claudealyzer` and update the imports, so `go install` and pkg.go.dev work.
- [x] **No license.** Add a `LICENSE` file (MIT or Apache-2.0) and a license badge in the README.
      Without a license, nobody can legally use the code.

## 2. The app still has Wails template values

- [x] `build/config.yml` still says `"My Company"`, `"My Product"`, `com.mycompany.myproduct`,
      `"A program that does X"`, `(c) 2025, My Company` and `0.0.1` (now 0.2.0). These end up in Info.plist, the
      Windows file properties, the installer and the `.desktop` file. Set real values, e.g.
      `io.github.<user>.claudealyzer`.
- [ ] Show the app version somewhere (an About window or the settings footer), so bug reports can say
      which version they are about.

## 3. Releases and CI

- [ ] `.github/workflows/ci.yml`: on each PR, run `go vet`, `go test ./...` and `ng build`.
- [ ] `.github/workflows/release.yml`: on a `v*` tag, build macOS (universal), Windows and Linux
      (AppImage/deb/rpm) on native runners and attach the files to a GitHub Release.
- [ ] Make the release file names match the README's Installation table.
- [x] Keep a `CHANGELOG.md` (added). Still to do: generate release notes from it.
- [ ] Optional: macOS notarization (needs an Apple Developer account). Until then the `xattr` note in
      the README stays.

## 4. Community files

- [x] `CONTRIBUTING.md`: short, links to DEVELOPMENT.md, covers commit style, adding an adapter and
      updating prices.
- [x] `SECURITY.md`: how to report a vulnerability privately (GitHub private advisories). The app reads
      sensitive transcripts, so people will look for this.
- [x] Issue templates: bug report (OS, version, agent), new agent support, pricing update.
- [x] PR template and `CODE_OF_CONDUCT.md` (Contributor Covenant).
- [ ] Repo settings: description, topics (`claude-code`, `codex`, `gemini-cli`, `wails`, `angular`,
      `token-usage`), website URL, social preview image (`docs/images/history.png`).

## 5. Tests and code quality

- [ ] Only 5 Go test files and no frontend tests. Add parser tests for each adapter that run on small
      fake transcripts under `testdata/`, so new adapters can copy the pattern and agent format changes
      are caught early.
- [ ] Add the screenshot mock-data generator (`gen_mock.py`) and the Playwright scripts under
      `scripts/screenshots/`, so screenshots can be remade after UI changes. The generator can also
      produce the test fixtures.
- [ ] Lint: `golangci-lint`, plus ESLint or Prettier for the frontend.
- [ ] Dependabot or Renovate for Go modules, npm and GitHub Actions.

## 6. Accuracy of the shipped data

- [ ] The OpenAI and Google rows in `internal/pricing/default_pricing.json` are marked `placeholder`.
      Fill in real prices with a `source` and date, or mark these rates as estimates in the UI.
- [ ] Say in the README that agent transcript formats are undocumented and can change, and list the
      agent versions that were tested.

## 7. Cleanup before the first push

- [x] `build/windows/nsis/MicrosoftEdgeWebview2Setup.exe` (1.7 MB, Microsoft binary): now git-ignored; the
      Windows build step downloads it.
- [x] `build/linux/claudealyzer.desktop`: generated by the Linux build, now git-ignored.
- [ ] `build/darwin/Assets.car` shows as modified: commit or revert it on purpose.
- [ ] Remove unused template folders such as `build/android/` and `build/ios/`.
- [ ] `.gitignore`: add `*.tgz` once the npm packages exist.
- [ ] Convert `docs/images` (~12 MB of PNGs) to WebP before they are in the history for good.
- [x] Git history checked: the only personal detail is the GitHub noreply address in the author lines.
      No local paths or emails in the diffs, so the history can be pushed as it is.
- [x] Replace `YOUR-GITHUB-USER` in `README.md` and in `docs/index.html` (`window.REPO`).
